# Forward Focus Counseling LLC website

Static, SEO-ready website prepared for GitHub Pages and `forwardfocuscounseling.org`.

## Publish on GitHub Pages
1. Create a public GitHub repository (for example `forward-focus-counseling`).
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages** and publish from the `main` branch, root folder.
4. In **Custom domain**, enter `forwardfocuscounseling.org`.
5. At your domain registrar, point the apex domain to GitHub Pages using GitHub's current A/AAAA records, and set `www` as a CNAME to your GitHub Pages hostname.
6. After DNS verifies, enable **Enforce HTTPS**.
7. Add the site to Google Search Console and submit `https://forwardfocuscounseling.org/sitemap.xml`.
